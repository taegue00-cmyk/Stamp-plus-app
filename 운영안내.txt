[ 먼저 알아 둘 것 ]
- 스탬프 기록은 "사장님 기기(컴퓨터나 휴대폰) 안"에만 저장돼요.
- 그래서 적립도, 손님 확인도 항상 "그 기기"에서 해요.
  손님이 자기 휴대폰으로 확인하는 것은 안 돼요.
- 파일은 2개만 써요.
    admin.html  → 적립할 때 (사장님·직원용, 손님에게 보여 주지 않기)
    index.html  → 손님이 스탬프를 확인할 때
- 두 파일은 항상 "같은 방법"으로 열어요.
  (파일을 두 번 눌러 열기, 또는 즐겨찾기로 열기 중 하나만 정해서 계속 쓰기)
  방법을 섞으면 기록이 따로따로 저장돼서 스탬프가 안 보여요.
- 시크릿(비공개) 창에서는 열지 마세요. 닫으면 기록이 사라져요.


--------------------------------------------------
1. 손님에게 이렇게 안내하세요 (예시 문구)
--------------------------------------------------
[처음 오신 손님]
 "저희 가게는 스탬프를 모으면 무료 음료를 드려요.
  음료 1잔 사실 때마다 스탬프 1개를 적립해 드릴게요.
  10개 모으시면 음료 1잔이 무료예요!"

[번호를 물어볼 때]
 "적립 도와드릴게요.
  휴대폰 번호 뒷 4자리만 알려 주세요.
  이름이나 전체 번호는 필요 없어요."

[적립 후]
 "적립해 드렸어요. 지금 3개 모으셨어요. 7개 더 모으시면 무료 음료예요!"

[손님이 개인정보를 걱정하실 때]
 "뒷 4자리 숫자만 쓰고, 이름과 전체 번호는 저장하지 않아요."

[10개를 모으신 손님]
 "축하드려요! 스탬프 10개를 모두 모으셨어요.
  무료 음료 1잔 드릴게요. 어떤 음료로 하시겠어요?"

[스탬프를 확인하고 싶어 하는 손님]
 "제 화면으로 보여 드릴게요. 뒷 4자리만 알려 주세요."
 (직원이 index.html 을 열어서 보여 주기)

※ 손님에게 "사장님 화면 주소(admin.html)"나 비밀번호는 절대 알려 주지 마세요.


--------------------------------------------------
2. 사장님 화면에 들어가는 법
--------------------------------------------------
 1) 정해 둔 방법으로 admin.html 을 열어요.
 2) "비밀번호를 넣어 주세요" 화면이 나와요.
 3) 숫자 4자리 비밀번호를 넣고 [들어가기]를 눌러요.
    - 처음 쓰는 날에는 "비밀번호 만들기"가 나와요.
      사장님만 아는 숫자 4자리를 정하세요.
      (1234, 0000, 생일 같은 쉬운 숫자는 피하세요)
 4) 끝나면 맨 아래 [잠그기]를 눌러 주세요.
    - 손님이 있는 계산대 근처에서는 꼭 잠가 두세요.

※ 비밀번호는 종이에 적어 사장님만 아는 곳에 보관하세요.
   잊어버리면 되살리는 버튼이 없어요. (6번 참고)


--------------------------------------------------
3. 적립하는 법
--------------------------------------------------
 1) 손님에게 "휴대폰 번호 뒷 4자리"를 물어봐요.
 2) 칸에 숫자 4개를 넣어요.
    - 4개가 되기 전에는 [적립] 버튼이 흐리고 눌리지 않아요.
 3) 큰 [적립 (+1)] 버튼을 눌러요.
 4) 아래에 "지금 3 / 10개" 와 동그라미가 바로 나와요.
    - 화면 아래쪽에 "저장됨 ✓" 이 잠깐 보이면 저장 성공이에요.
 5) 손님에게 개수를 알려 주세요.

 * 처음 온 손님은 따로 등록하지 않아도 [적립]을 누르면 자동으로 만들어져요.
 * 화면 맨 아래에 "오늘 적립한 횟수"가 나와요. 마감할 때 확인하세요.

[1분 안에 같은 손님에게 또 적립하려고 하면]
 "방금 적립했습니다. 계속할까요?" 창이 떠요.
  - 정말 한 잔 더 사신 거면 [확인]
  - 실수로 두 번 누른 거면 [취소]


--------------------------------------------------
4. 실수했을 때 되돌리는 법
--------------------------------------------------
[잘못 적립했을 때]
 1) 같은 손님 번호 4자리를 넣어요.
 2) [취소 (-1)] 버튼을 눌러요.
 3) 스탬프가 1개 줄어들고, 오늘 적립 횟수도 1 줄어요.

[번호를 잘못 넣어서 다른 손님에게 적립했을 때]
 1) 잘못 넣었던 번호를 다시 넣어요.
 2) [취소 (-1)]을 눌러요.
 3) 맞는 번호를 넣고 [적립 (+1)]을 눌러요.

※ [취소]는 확인 창 없이 바로 빠져요. 누르기 전에 번호를 한 번 더 보세요.


--------------------------------------------------
5. 무료 음료를 드리고 초기화하는 법
--------------------------------------------------
 1) 손님 번호 4자리를 넣고 [적립] 또는 확인을 해요.
    (스탬프가 10개 찬 손님이에요)
 2) 화면에 노란 글씨로
      "무료 음료 제공 대상입니다"
    가 크게 떠요.
 3) 먼저 손님에게 무료 음료를 만들어 드려요. (순서 중요!)
 4) 음료를 드린 "다음에" 초록색 [사용 완료] 버튼을 눌러요.
 5) "0개로 되돌릴까요?" 확인 창이 떠요. 맞으면 [확인]을 눌러요.
 6) 스탬프가 0개로 돌아가요. 이제 새로 모을 수 있어요.

 * 10개가 찬 손님에게는 [사용 완료]를 누르기 전까지 적립이 되지 않아요.
 * [사용 완료]는 되돌릴 수 없어요. 음료를 드리기 전에는 누르지 마세요.


--------------------------------------------------
6. 문제가 생겼을 때 확인할 것 3가지
--------------------------------------------------
[확인 1] 스탬프가 사라졌거나 0개로 나와요
  - 어제와 "같은 방법"으로 열었나요?
    (두 번 눌러 열기 / 즐겨찾기 / 편집 프로그램 미리보기가 섞이면 따로 저장돼요)
  - 시크릿(비공개) 창이 아닌가요?
  - 같은 브라우저(크롬 등)인가요?
  - 해결: 원래 쓰던 방법과 브라우저로 다시 열어 보세요.
  - 그래도 없으면, 저장해 둔 백업 파일을 불러와요.
      index.html → 사장님 탭 → 맨 아래 [백업 파일 불러오기]

[확인 2] 적립 버튼이 안 눌리거나, 번호가 이상해요
  - 숫자가 정확히 4개인가요? (3개 이하면 버튼이 흐려요)
  - 손님이 말한 번호가 맞나요? 한 번 더 확인해요.
  - "같은 번호의 손님이 있어요. 골라 주세요" 가 뜨면,
    뒷 4자리가 같은 다른 손님이 있다는 뜻이에요.
    목록에서 별명을 보고 맞는 손님을 눌러요.
  - 화면이 이상하면 새로고침(F5)을 눌러요. 저장된 기록은 그대로예요.

[확인 3] "저장이 안 되었어요" 라고 빨간 글씨가 떠요
  - 휴대폰·컴퓨터 저장 공간이 가득 찼을 수 있어요.
    안 쓰는 사진이나 앱을 지워 공간을 만든 뒤 다시 눌러요.
  - 적립 후 "저장됨 ✓"이 보이지 않았다면, 같은 손님 번호를 넣고
    개수를 확인한 뒤 필요하면 다시 적립해요.
  - 계속 안 되면 사장님께 알려 주세요.

[비밀번호를 잊어버렸어요]
  - 직원이 풀 수 있는 방법은 없어요. 사장님께 말씀드려 주세요.
  - 사장님도 모르면 개발 도움이 필요해요. 그 전에 백업 파일부터 저장해 두세요.


--------------------------------------------------
7. 사장님이 꼭 하실 일
--------------------------------------------------
 - 일주일에 한 번, 백업 파일을 저장하세요.
     사장님 화면 맨 아래 [💾 백업 파일 저장]
   7일이 지나면 화면에 알려 줘요.
 - 백업 파일에는 손님 뒷자리 번호가 들어 있어요.
   메신저나 공유 폴더에 아무렇게나 올리지 마세요.
 - 휴대폰이나 컴퓨터를 바꾸거나, 인터넷 사용 기록을 지우기 전에는
   반드시 백업 파일을 먼저 저장하세요.
 - 손님 이름과 전체 전화번호는 받지도, 적지도 마세요.
   (뒷 4자리만 써요)
