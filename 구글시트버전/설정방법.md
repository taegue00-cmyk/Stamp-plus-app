# 구글 시트로 스탬프 저장하기 — 설정 방법

한 번만 하면 돼요. 약 15분 걸려요. 컴퓨터로 하는 걸 추천해요.
**1~4번은 구글 시트 화면, 5번은 저한테 알려 주는 것, 6번은 인터넷 주소 만들기예요.**

---

## 1번. 구글 시트 만들기  (화면: 구글 시트)
1. 인터넷 주소창에 `sheets.new` 를 치고 Enter를 눌러요.
2. 빈 시트가 열려요. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 **브릿지 스탬프 장부**로 바꿔요.

## 2번. "심부름꾼" 글 붙여 넣기  (화면: 구글 시트 → Apps Script)
1. 맨 위 메뉴에서 **확장 프로그램 → Apps Script** 를 눌러요. 새 창이 열려요.
2. 가운데 칸에 `function myFunction() {}` 같은 글이 있어요. **전체 선택(Ctrl+A)** 하고 지워요.
3. 이 폴더의 **`구글시트용코드.txt`** 를 열어서 **전부 복사(Ctrl+A, Ctrl+C)** 한 다음, 방금 비운 칸에 **붙여 넣어요(Ctrl+V)**.
4. 맨 위 근처 `PIN: '0000',` 에서 **0000 을 사장님 비밀번호 숫자 4자리로 바꿔요.**
   - 0000, 1234 같은 쉬운 숫자는 피해 주세요.
   - 원하면 바로 아래 `GOAL`(몇 개 모으면 보상), `REWARD`(보상 이름)도 바꿔요.
5. 위쪽의 디스크 모양 **저장(💾)** 버튼을 눌러요.

## 3번. 처음 설정 실행하기  (화면: Apps Script)
1. 위쪽 가운데에 함수를 고르는 칸이 있어요. **`처음설정`** 을 골라요.
2. 옆의 **▶ 실행** 을 눌러요.
3. "권한 검토" 창이 뜨면 **권한 검토 → 사장님 구글 계정 선택** 을 눌러요.
4. "Google에서 확인하지 않은 앱" 이라는 경고가 떠도 정상이에요. 사장님이 직접 만든 글이라서 그래요.
   **고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용** 을 눌러요.
5. 아래에 "설정 완료!" 비슷한 글이 보이면 성공이에요. 구글 시트로 돌아가면 **손님**, **기록** 탭이 생겨 있어요.
6. (선택, 안전을 위해 추천) Apps Script 글로 돌아와서 `PIN: '숫자4자리'` 의 숫자를 **지우고 `''` 로** 바꾼 뒤 저장해요. 비밀번호는 이미 안전한 곳에 저장됐어요.

## 4번. 인터넷에 공개하기 (배포)  (화면: Apps Script)
1. 오른쪽 위 파란 **배포 → 새 배포** 를 눌러요.
2. "유형 선택" 옆 톱니바퀴 ⚙ 를 누르고 **웹 앱** 을 골라요.
3. 이렇게 맞춰요.
   - 설명: `브릿지 스탬프`
   - **다음 사용자로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자**
4. **배포** 를 눌러요. (권한 허용이 또 나오면 허용해요.)
5. **웹 앱 URL** 이 나와요. `https://script.google.com/macros/s/…/exec` 로 끝나는 긴 주소예요. **복사** 해 둬요.

> 나중에 "구글시트용코드.txt"를 고치면 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포** 를 해야 반영돼요. 주소는 그대로예요.

## 5번. 주소를 저한테 알려 주기  (화면: 이 대화창)
- 4번에서 복사한 **웹 앱 URL** 을 대화창에 붙여 넣어 주세요.
- 저는 그 주소를 `index.html` 과 `admin.html` 에 넣고, 올리기만 하면 되는 **`올리기용`** 폴더를 만들어 드려요.
- (직접 넣고 싶으면 두 파일에서 `여기에_구글_주소를_붙여_넣으세요` 를 찾아서 주소로 바꿔요.)

## 6번. 무료 인터넷 주소 만들기 — Netlify  (화면: 인터넷 브라우저)
손님이 자기 폰으로 열려면 필요해요.
1. `app.netlify.com/drop` 에 가요. 처음이면 **무료 계정**을 만들어요. (카드 등록은 필요 없어요.)
2. 파일 탐색기에서 **`올리기용`** 폴더를 열고, 그 **폴더째로** 인터넷 창의 점선 칸에 끌어다 놓아요.
3. 잠시 뒤 `https://랜덤이름.netlify.app` 같은 주소가 생겨요.
   - 손님용: `https://랜덤이름.netlify.app/` (또는 `/index.html`)
   - 사장님용: `https://랜덤이름.netlify.app/admin.html` ← **손님에게 알려 주지 마세요.**
4. 사이트 이름을 바꾸고 싶으면 Netlify의 **Site configuration → Change site name** 에서 바꿔요.
5. **중요:** 계정을 만들어 올려야 주소가 계속 살아 있어요. 계정 없이 올리면 1시간 뒤에 사라질 수 있어요.

## 7번. 잘 되는지 확인하기
1. 사장님 폰에서 사장님용 주소를 열고, 비밀번호를 넣고 들어가요.
2. 뒷자리 `0000` 을 넣고 **적립** 을 눌러요. "저장됨 ✓" 이 나와요.
3. **다른 폰**(또는 다른 창)에서 손님용 주소를 열고 `0000` 을 넣고 **확인** 을 눌러요. 스탬프 1개가 보이면 성공이에요!
4. 구글 시트의 **손님** 탭에 `0000` 이 한 줄 생겼는지도 봐요. 확인이 끝나면 그 줄은 지워도 돼요.

---

## 자주 묻는 것
- **사장님이 적립하면 손님 화면에 바로 나오나요?** 손님이 **확인**을 누르거나 **새로고침**하면 최신 숫자가 나와요. 가만히 두면 저절로 바뀌지는 않아요.
- **비밀번호를 잊었어요.** Apps Script에서 `PIN` 숫자를 새 숫자로 쓰고 **`처음설정` 을 다시 실행**하면 바뀌어요.
- **비밀번호를 5번 틀렸어요.** 10분 기다리면 풀려요.
- **구글 시트 손님 목록은 어디서 봐요?** 구글 시트의 **손님** 탭에 있어요. 별명 칸(B)은 사장님이 시트에서 직접 적으면 사장님 화면에만 보여요.
- **적립 기록은요?** **기록** 탭에 언제 누구에게 무엇을 했는지 한 줄씩 쌓여요.

## ⚠️ 꼭 지켜 주세요
- 구글 시트를 **다른 사람과 공유하지 마세요.** 손님 뒷자리가 들어 있어요.
- 사장님용 주소와 비밀번호를 손님에게 알려 주지 마세요.
- 손님 이름이나 전체 번호는 시트에 적지 마세요.
- 손님 화면은 뒷자리 4개만 알면 누구나 스탬프 개수를 볼 수 있어요. (이름은 안 나와요.)
