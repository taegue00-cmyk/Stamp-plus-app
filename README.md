# 🌸 브릿지 스탬프 — 단골 적립 스탬프 웹앱

작은 가게를 위한 **종이 도장판 대신 쓰는 스탬프 적립 웹앱**입니다.
음료 한 잔에 스탬프 하나, **10개를 모으면 무료 음료** 한 잔을 드립니다.

설치도 회원가입도 필요 없습니다. **파일을 두 번 누르면 바로 열립니다.**

---

## 특징

- 📱 **휴대폰 화면 기준** — 손가락으로 누르기 편한 큰 버튼
- 🧊 **글래스모피즘** — 반투명 카드, 부드러운 그림자, 둥근 모서리
- 🇰🇷 **화면의 모든 글자가 한국어**
- 🔒 **손님 정보는 전화번호 뒷 4자리만** — 이름과 전체 번호는 받지 않습니다
- 💾 **이 기기에만 저장** — 서버도 데이터베이스도 없습니다
- 🛠 **HTML · CSS · JavaScript만 사용** — 프레임워크 없이 파일 하나로 한 화면이 완성됩니다

---

## 파일 구성

| 파일 | 무엇인가요 |
|---|---|
| `index.html` | **손님 확인 + 사장님 관리 화면** — 손님 확인, 손님 목록, 설정, 백업 |
| `admin.html` | **사장님 전용 빠른 적립 화면** — 큰 버튼으로 적립·취소·사용 완료 |
| `손님화면.html` | **연습용 손님 화면** — 저장 기능 없이 예시 숫자만 보여 줍니다 (`1234`=3개, `5678`=7개, `9999`=10개) |
| `운영안내.txt` | **직원용 안내서** — 개발을 몰라도 읽고 따라 할 수 있게 정리 |
| `CLAUDE.md` | 이 프로젝트의 작업 규칙 |
| `이전버전/` | 수정 전 파일 보관 |
| `구글시트버전/` | 구글 시트에 저장하는 방식의 시도본 (**아직 실제로 연결해 시험하지 않았습니다**) |

## 바로 써 보기

1. 이 저장소를 내려받습니다. (초록색 **Code → Download ZIP**)
2. 압축을 풉니다.
3. `admin.html`을 **크롬(Chrome) 또는 엣지(Edge)** 로 엽니다.
4. 처음이면 **사장님만 아는 숫자 4자리 비밀번호**를 정합니다.
5. 뒷자리 4개(예: `5555`)를 넣고 **[적립 (+1)]** 을 누릅니다.
6. 같은 브라우저에서 `index.html`을 열고 **손님 확인**에 `5555`를 넣으면 스탬프가 보입니다.

> ⚠️ 두 파일은 **항상 같은 방법, 같은 브라우저**로 여세요. 방법이 다르면 저장 공간이 따로 생겨 기록이 안 보입니다.

## 화면 소개

### 손님 확인 (`index.html`)

- 뒷 4자리를 넣으면 지금 모은 스탬프를 동그라미로 보여 줍니다
- 10개를 모두 모으면 **꽃가루가 날리는 축하 화면**이 나옵니다
- 사장님 탭에서는 손님 목록, 보상 개수·이름 설정, 백업을 할 수 있습니다

### 사장님 전용 (`admin.html`)

- 비밀번호 4자리로 잠금
- **[적립 (+1)]** — 4자리를 다 넣어야 눌립니다
- **[취소 (-1)]** — 실수했을 때 1개 빼기
- 10개가 되면 **"무료 음료 제공 대상입니다"** 알림, 음료를 드린 뒤 **[사용 완료]** 로 0개로 초기화
- 같은 손님에게 **1분 안에 두 번 적립하면 한 번 더 물어봅니다**
- **사용 완료는 확인 창**을 한 번 더 띄웁니다
- 화면 아래에 **오늘 적립한 횟수** 표시
- 적립이 저장되면 "저장됨 ✓", 실패하면 빨간 경고

## 데이터가 어디에 저장되나요

**기기 안(브라우저의 `localStorage`)에만 저장됩니다. 인터넷으로 아무것도 보내지 않습니다.**

- 손님 정보: 뒷 4자리, 별명(선택), 스탬프 개수, 받은 선물 횟수
- 설정: 모으는 개수, 보상 이름, 사장님 비밀번호

### ⚠️ 꼭 지켜야 하는 3가지

1. **두 파일을 같은 방법, 같은 브라우저로 여세요.**
2. **시크릿(비공개) 창으로 열지 마세요.** 창을 닫으면 기록이 사라집니다.
3. **"사이트 데이터 삭제"를 하지 마세요.** 스탬프가 같이 지워집니다.

### 손님 화면은 이 기기에서만 볼 수 있어요

기록이 사장님 기기에만 있어서, 손님이 자기 휴대폰으로 확인할 수는 없습니다.
가게에서 직원이 사장님 기기로 보여 줍니다.

## 백업과 복원

기기를 바꾸거나 브라우저 기록을 지우면 스탬프가 사라집니다. **일주일에 한 번** 백업하세요.
7일이 지나면 화면에서 알려 줍니다.

- **백업 저장:** `admin.html` 아래 또는 `index.html` 사장님 탭의 **[백업 파일 저장]** → `.json` 파일이 만들어집니다
- **불러오기:** `index.html` 사장님 탭의 **[백업 파일 불러오기]** (지금 기록이 백업 내용으로 바뀝니다)
- 백업 파일에는 **사장님 비밀번호를 넣지 않습니다.**

---

## 🔐 보안에 대해 솔직히

- **비밀번호 4자리는 약한 잠금입니다.** 손님이 실수로 만지는 것은 막지만, 브라우저를 다룰 줄 아는 사람이 일부러 열려고 하면 막을 수 없습니다. 은행이나 휴대폰 잠금 번호는 쓰지 마세요.
- 비밀번호는 코드에 적혀 있지 않고, **처음 쓸 때 사장님이 정해** 그 기기에만 저장됩니다.
- 비밀번호를 잊었을 때 되살리는 버튼은 아직 없습니다.
- 백업 파일에는 **손님 뒷 4자리 명단**이 들어 있습니다. 아무에게나 보내지 마세요.
- 이름과 전체 전화번호는 **받지도, 적지도 마세요.**

## 설정 바꾸기

- **몇 개를 모으면 보상?**, **보상 이름:** `index.html` → 사장님 탭 → **설정**
- 비밀번호는 지금 화면에서 바꾸는 기능이 없습니다.

## 만든 방법

- **HTML · CSS · JavaScript** 만 사용 (프레임워크·빌드 도구 없음)
- 저장은 브라우저의 `localStorage`
- 글꼴: 고운 돋움 → 맑은 고딕 순서 (고운 돋움은 인터넷에서 불러오며, 안 되면 맑은 고딕으로 보입니다)
- 코드와 주석은 한국어입니다
